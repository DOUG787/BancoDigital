# Banco Digital com POO em Java 💻🏦

Projeto simples em Java que simula um banco digital utilizando os princípios da Programação Orientada a Objetos (POO).

## 🧱 Funcionalidades

- Abertura de contas correntes e poupança
- Depósito, saque e transferência
- Impressão de extrato bancário
- Uso de abstração, herança e polimorfismo

## 📂 Estrutura do Projeto

- `Conta` (classe abstrata)
- `ContaCorrente` e `ContaPoupanca`
- `Cliente`
- `Banco`
- `Main` para execução do programa
